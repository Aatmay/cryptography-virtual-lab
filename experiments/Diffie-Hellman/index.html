Theoretical Background: Diffie–Hellman Protocol

Diffie–Hellman key exchange is an asymmetric cryptographic mechanism developed by Whitfield Diffie and Martin Hellman in 1976. It provides a means for two communicative entities to establish a shared symmetric cryptographic key over an unencrypted communication channel.

Algebraically, it can be shown that
ka = kb

2. Mathematical Proof of Equivalence

Both parties arrive at the identical secret key because of modular exponentiation power laws:

Alice computes: ka = (y)a mod P = (Gb)a mod P = Ga · b mod P
Bob computes: kb = (x)b mod P = (Ga)b mod P = Ga · b mod P
Since both expressions evaluate to Ga · b mod P, it follows that:
ka = kb

Laboratory Procedure

  1. Parameter Agreement: Both endpoints agree upon global public parameters: prime modulus P and primitive root G.
  2. Private Key Selection: Alice chooses private integer a (where a < P). Bob chooses private integer b (where b < P).
  3. Public Key Generation: Alice computes x = Ga mod P. Bob computes y = Gb mod P.
  4. Key Exchange: Alice and Bob send their generated keys x and y over the insecure channel. Alice receives y, and Bob receives x.
  5. Secret Key Derivation: Alice calculates ka = ya mod P. Bob calculates kb = xb mod P. Verify that ka = kb.
